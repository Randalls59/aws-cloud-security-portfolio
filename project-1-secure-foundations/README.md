# Project 1 — Secure AWS Foundations Lab

**Status:** 🔄 In Progress
**Roadmap days:** 1–21
**AWS account:** 414649800199 (us-east-1)

## Goal

Build a real AWS security lab from scratch covering IAM, S3, VPC,
EC2, CloudTrail, and CloudWatch. Every service has a documented
security reason.

## Services Used

IAM · S3 · VPC · EC2 · CloudTrail · CloudWatch · SNS · Linux

## What This Proves

- I can configure IAM with least privilege
- I understand VPC network isolation
- I know how to harden an EC2 instance
- I can enable and verify audit logging with CloudTrail
- I understand monitoring and alerting with CloudWatch
